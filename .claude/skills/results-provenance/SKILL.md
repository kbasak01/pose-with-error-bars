# Results provenance

## The rule
A number may appear in README, docs, a table or a figure only if it is read from a committed file
under `results/`. Tables and figures are generated by `scripts/make_tables.py` and
`scripts/make_figures.py` from those files, never typed. `inf` is a value: keep it.

## Required fields in every result JSON
```
{
  "schema": "poseconf.result.v1",
  "kind": "coverage" | "level_a" | "level_b" | "variance_head" | "parity" | "latency" | "dump_summary",
  "score": "A1", "arm": "split", "convention": "abstain_allowed",
  "alpha": 0.10, "domain": "lightbox", "subset": "lightbox_poolB", "crop_source": "predicted_crop",
  "oracle": false,
  "n_total": 0, "n_answered": 0,
  "coverage": 0.0, "coverage_ci95": [0.0, 0.0],
  "answer_rate": 0.0, "silent_failure_rate": 0.0,
  "set_size": {"rot_deg": {"median": 0.0, "p90": 0.0}, "trans_frac": {...}, "kp_px": {...}},
  "quantile": 0.0, "n_cal": 0,
  "provenance": {
    "poseconf_git_sha": "...", "p1_commit": "0f81b426...", "p1_checkpoint_sha256": "...",
    "split_manifest_sha256": "...", "config_sha256": "...", "created_at": "ISO-8601",
    "pnp_config": {...copied from the P1 run config...}
  }
}
```
Use `float("inf")` serialised as the string `"inf"` (JSON has no infinity); readers convert back.
`oracle` is true for every `gt_crop` row on a HIL domain and every `oracle_*` arm.

## Tables
- State convention, arm, α, and n in every table caption.
- Coverage always with `[CI]` and answer rate beside it.
- Oracle rows in their own labelled sub-table.
- Footnote every `—` with the reason the cell is empty.

## Figures
- Title says what is plotted and the convention/arm.
- HIL imagery in a figure → caption carries "SPEED+ imagery, CC BY-NC-SA 4.0".
- Regenerable from `results/` + (optionally) gitignored `dumps/`; skipped with a message when inputs
  are absent, raising when asked for by name.

## Before writing a sentence with a number
Find the file, open it, copy the value, keep its precision, name the file in a nearby link.
